# For Catherine

Live website: https://mr-leek.github.io/CatHBD/

A birthday surprise password screen opens a cinematic story with seven photographs, four tap-controlled necklace faces, a birthday greeting and Bai’s final scene. Replay starts the story again. Reduced motion, portrait and landscape layouts are supported.

The password is necessarily visible in public client-side code; this is a surprise screen, not secure authentication. No password or unlock state is persisted. The initial HTML includes noindex, nofollow, noarchive and noimageindex. These request non-indexing and do not guarantee removal from search results. No robots.txt blocking rule is used.

Text and timing are configured in script.js. All asset paths support GitHub Pages under /CatHBD/. The approved version was tested in Chrome and WebKit.

Sentimental Piano – Grand_Project is still missing. Add the exact track at assets/music.mp3 to enable music; the current version runs silently. No replacement track is bundled.
